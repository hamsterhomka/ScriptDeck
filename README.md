# ScriptDeck

Нативное macOS-приложение (SwiftUI) для запуска npm / yarn / pnpm / bun скриптов — вместо того чтобы держать открытой IDE только ради панели npm.

## Возможности

- **Вкладки проектов** сверху, как в WebStorm. Вкладка — папка проекта или *мастер-папка* с несколькими проектами внутри (сканируется на 2 уровня, `node_modules`, `dist`, `*.worktrees` и т.п. пропускаются).
- **Три колонки** для мастер-папки: проекты → скрипты → лог. Проекты перетаскиваются, порядок запоминается.
- **Главная вкладка** — все запущенные на Mac скрипты: из ScriptDeck, WebStorm, терминала, а также процессы других пользователей (только просмотр). Показывает порты, папку, откуда запущен, и находит осиротевшие dev-серверы.
- **Закреплённые скрипты**: по умолчанию на виду `dev`, `dev:*`, `start`, остальное свёрнуто в «Ещё N». Скрипты сортируются по частоте запуска.
- **Лог** с ANSI-цветами, кликабельными ссылками, поиском (⌘F) и автоопределением `localhost`-адреса для кнопки «Открыть в браузере».
- **Корректная остановка**: гасится всё дерево процессов (yarn → node → esbuild), в том числе при выходе из приложения и при `kill`.
- **Окружение из login-shell** — nvm, yarn и прочее из `~/.zshrc` подхватываются.
- Иконка в меню-баре, тёмная тема с палитрами WebStorm / Claude / Cursor.

## Горячие клавиши

| | |
|---|---|
| ⌘R / ⇧⌘R / ⌘. | запустить-остановить / перезапустить / остановить |
| ⌘K | очистить лог |
| ⇧⌘O | открыть адрес в браузере |
| ⌘P | поиск скрипта |
| ⌘T | открыть папку новой вкладкой |
| ⌘0, ⌘1…9, ⇧⌘[ / ⇧⌘] | вкладки |

## Сборка

Требуется macOS 15+ и Xcode / Swift 6.

```bash
./scripts/make-app.sh            # build/ScriptDeck.app
./scripts/make-app.sh --install  # и установить в /Applications
```

Отладка сканера системных процессов: `.build/debug/ScriptDeck --scan`.
